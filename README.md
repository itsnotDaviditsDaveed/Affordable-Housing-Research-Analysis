# NYC Affordable Housing 2023: Mapping in Python

**Tools:** Python · pandas · Plotly · Jupyter

My first look at NYC's 2023 affordable housing data, using Python. I focused on mapping every building with Plotly and comparing boroughs. I later went deeper with SQL and Tableau in [NYC Affordable Housing 2023 (SQL + Tableau)](https://github.com/itsnotDaviditsDaveed/2023-Affordable-Housing-Research-Analysis).

![All projects map](MORE%20pandas/images/All_Projects.png)

## What I Built

- An interactive map of all 700 buildings, colored by borough
- Separate maps for Queens, the Bronx, Brooklyn, and Manhattan
- A comparison of units by income level
